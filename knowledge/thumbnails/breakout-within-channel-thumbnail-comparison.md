## Portable thumbnail lessons

1. **Relational anchors beat polish.** Faces and relationship roles must remain readable; spectacle cannot substitute for emotional orientation.
2. **One dominant question.** Hidden Beauty asks “who threatens/protects this beautiful girl?” Tiny Kingdom asks “what is this tiny joyful hidden world?” Low performers often either over-stack tropes or show outcome/spectacle without a question.
3. **Wonder can replace threat only when scale novelty plus companionship are visible.** Tiny Kingdom is joyful, but not empty: child + explorer + creature/vehicle + scale object create a complete visual premise.
4. **Text should not behave like credits.** “Created and designed by” consumes attention without sharpening the story promise.
5. **Do not overgeneralize child/creature presence.** Mermaid child imagery can still underperform when tropes are cluttered and conflict/protection is unclear.
6. **If the premise is protection, the thumbnail must show the protected object or bond.** Glass Dragon’s battle spectacle hides the emotional engine.

## Integration rules for future concept generation

- For exploration wonder: require explorer emotion + companion/creature + scale object in the concept sheet.
- For transformation melodrama: require vulnerable protagonist + ally/antagonist social triangle before cosmetic beauty polish.
- For creature fantasy: require the vulnerable creature/child or bond cue; reject creature-battle spectacle if no relational object is visible.
- For high-concept spectacle: one threat only, one focal human, no multi-trope clutter.
